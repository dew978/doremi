# 도레미 작곡 공책

초등학생을 위한 8마디 작곡 프로그램이에요. 조와 박자, 빠르기를 정하고, 음표와 쉼표를 악보에 끌어다 놓아 가락을 만든 뒤 피아노나 리코더 소리로 악보대로 연주해요.

**바로 쓰기:** https://dew978.github.io/doremi/

- 조: 다장조·사장조·라장조·바장조·내림나장조, 가단조·마단조·라단조
- 박자: 2/4, 3/4, 4/4, 6/8
- 빠르기: Largo~Presto 빠르기말 기준 + 자유 조정(♩=40~200)
- 온음표~16분음표, 점음표, 쉼표, ♯·♭·♮
- 음표 위에 겹쳐 놓으면 화음(3음까지)
- 드럼 반주, 메트로놈

삼대 710 제작
